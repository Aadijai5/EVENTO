
# EVENTO

### Discover Events. Connect with People. Create Experiences.

EVENTO is an event discovery and management platform designed to help students explore events, register for activities, and manage their digital event tickets.

## Features

- Event discovery and browsing
- Search and category filters
- Event details
- Student event registration
- My Registered Events dashboard
- Digital QR code tickets
- Light and Dark themes
- Responsive user interface

## Technology Stack

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend (Planned)**
- Node.js
- Express.js
- PostgreSQL

## Running the Project

1. Clone or download the repository.
2. Open the project in VS Code.
3. Install the Live Server extension.
4. Open `frontend/index.html`.
5. Select Open with Live Server.
